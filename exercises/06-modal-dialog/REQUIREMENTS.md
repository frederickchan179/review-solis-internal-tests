# Requirements — Newsletter Signup Modal

- While the modal is open, the page behind it must not scroll.
- All content inside the modal dialog (including the terms text) must remain fully readable via scrolling *within* the dialog, even on a short viewport — nothing inside the dialog should ever be permanently cut off or unreachable.
- The modal must be fully operable using only a keyboard: it must be possible to open it, navigate everything inside it, and close it without a mouse.
- When the modal closes, keyboard focus must return to a sensible, predictable location.
